# LinkedEye-FinSpot Project

This is a Full Stack ITSM Application implementation.

## Project Structure
- **/client**: React + Vite Frontend
- **/server**: Node.js + Express Backend
- **PROJECT_PLAN.md**: Detailed architecture, diagrams, and flow.

## How to Run

### 1. Start the Backend Server
```bash
cd server
npm install
node src/app.js
```
The server will run on http://localhost:5001

### 2. Start the Frontend Client
```bash
cd client
npm install
npm run dev
```
The client will run on http://localhost:5173
